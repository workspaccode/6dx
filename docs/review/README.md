## إزاي اتعملت المراجعة

- **Backend:** اتعمله `go build` و `go vet` و `go test -tags=integration ./...` — **كله نجح ✅**.
- **Flutter:** Flutter مش متسطب في بيئة المراجعة، فالمراجعة بقراءة الكود فقط (من غير `flutter analyze` / `flutter test`).
- كل مشكلة مكتوب جنبها الملف ورقم السطر. الأرقام صحيحة على commit `7c6a2d7`؛ لو عدّلت الملفات الأرقام هتتحرك.

- 🟠 **عالي** — ميزة شكلها شغال وهي مش شغالة، أو بيانات بتضيع.
- 🟡 **متوسط** — سلوك غلط أو تجربة مستخدم سيئة.
- ⚪ **منخفض** — تنظيف أو تحسين.

## اللي اتحسن من النسخة الأولى

- تسجيل دخول GitHub بقى حقيقي بالـ device flow عن طريق الـ backend، والـ `client_secret` اتشال من التطبيق.
- البيانات الوهمية وطرق الدخول الوهمية (mock) اتشالت من الـ data layer.
- الـ backend نظيف: كل الـ SQL parameterized، كل route بيغيّر بيانات عليه `requireEditor`/`requireAdmin`، الـ `X-Workspace-Id` بيتأكد من العضوية، وإنشاء مساحة العمل جوه transaction.
